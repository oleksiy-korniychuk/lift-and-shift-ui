# Lift and Shift - Features

## User Account
- User registration and authentication
- Secure login to access personal workout data

## Workout Program Management
- Create custom workout programs with names and descriptions
- View a list of all your workout programs
- Select programs to manage their content

## Block Management
- Organize workout programs into training blocks
- Add multiple blocks to a program with block numbers and descriptions
- Select blocks to view and manage their content

## Day Management
- Create workout days within blocks with custom names and descriptions
- View all days within a selected block
- Select days to view and manage their exercises

## Exercise Management
- Add exercises to workout days with detailed specifications:
  - Exercise name
  - Sets and reps
  - Option to mark as main exercise
  - Additional notes for technique or instructions

## Workout Execution
- Start workouts from any day in your program
- Record actual performance for each set of each exercise:
  - Weight used
  - Actual reps completed
- Add or remove sets during a workout
- Automatic saving of workout data

## Workout History and Tracking
- Access complete workout history
- View details of past workouts including:
  - Date performed
  - Program, block and day information
  - Exercises completed with sets, reps, and weights

## User Interface
- Clean and intuitive navigation between programs, blocks, days, and exercises
- Quick access to workout history from the main programs screen
- Streamlined workout tracking interface
